🎮 四川麻将 Android App 项目
=====================================

📁 项目文件说明：
├── app/                          # 应用主目录
│   ├── src/main/java/           # Java/Kotlin源代码
│   ├── src/main/res/            # 资源文件（布局、图片、字符串等）
│   └── build.gradle             # 应用构建配置
├── gradle/                      # Gradle构建工具
├── build.gradle                 # 项目构建配置
├── settings.gradle              # 项目设置
├── 一键构建APK.bat              # 自动构建脚本（推荐）
├── 安装说明.md                  # 详细安装指南
├── 在线构建说明.md              # 在线构建方法
└── README.md                    # 项目介绍

🚀 快速开始：
1. 双击运行"一键构建APK.bat"
2. 等待构建完成（首次需要下载依赖）
3. 在 app\build\outputs\apk\debug\ 找到APK文件
4. 将APK安装到Android手机

📱 系统要求：
- Android 7.0 (API 24) 或更高版本
- 至少50MB存储空间
- 支持横屏显示

🎯 游戏特色：
✅ 经典四川麻将玩法（108张牌）
✅ 单机模式：1个玩家 vs 3个AI
✅ 四川话语音提示（胡、碰、杠等）
✅ 完整积分统计系统
✅ 游戏历史记录
✅ 智能AI对手

🔧 如果构建失败：
1. 确保已安装Java 8+
2. 检查网络连接
3. 尝试使用Android Studio
4. 参考"在线构建说明.md"

📞 技术架构：
- 开发语言：Kotlin
- 架构模式：MVVM
- 数据库：Room
- UI框架：Android View + Material Design
- 语音：TextToSpeech + MediaPlayer

🎮 游戏操作：
- 胡：当满足胡牌条件时点击
- 碰：当可以碰牌时点击
- 杠：当可以杠牌时点击
- 过：跳过当前操作

💯 积分规则：
- 胡牌：+10分
- 杠牌：+2分
- 可查看详细游戏记录和统计

注意：本项目仅供学习和娱乐使用，请合理安排游戏时间。
